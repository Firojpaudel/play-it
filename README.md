# play-it

got bored and wanted to listen to music offline on my iphone without paying for spotify premium or dealing with ads, so i built this.

## what it is
a spotify-style pwa that lets you search youtube, stream music, download tracks straight to your phone storage (indexeddb), and read synced lyrics. works fully offline on airplane mode.

## how to use on iphone
1. open the site on safari
2. hit share -> add to home screen
3. search whatever song, tap download, and listen offline

## tech
- vanilla html/css/js
- indexeddb for local offline audio
- mediasession api for lock screen / dynamic island controls
- lrclib for real-time lyrics
- github pages for free hosting
